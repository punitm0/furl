# Security

Furl deletes and rewrites files, so bugs that could remove the wrong thing, run unexpected code or leak data
matter a lot. Please report them privately instead of opening a public issue.

- Use GitHub's **Report a vulnerability** button on the Security tab of this repository, or
- email **hello@getfurl.app** with "Security" in the subject.

Include what you found, how to reproduce it, and which Furl version and macOS version you used. You'll get a
reply within a few days. Once a fix ships, you're welcome to be credited in the release notes.

Only the latest release gets security fixes.
